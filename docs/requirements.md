# 需求說明

## 這是什麼
一個不用登入的匿名聊天室。所有人在同一個聊天室裡。

## 誰會用
任何知道網站連結的人都可以進來用, 可以用電腦, 也可以用手機來操作。

## 使用的流程
1. 打開網頁
2. 輸入一個代號
3. 進入聊天室，看到其他人的訊息，也可以送出訊息
4. （其他你想到的）

## 畫面上要有
- 誰在線上
- 有人進來或離開時要有提示
- （其他你想要的）

## 不需要的
- 註冊、登入
- （其他你確定不要的）

## 技術上我知道的
- 網頁放在 GitHub Pages
- 即時傳訊用 Supabase，透過 WebSocket
- 畫面設計用 /design，前端用 /frontend-design 做出來

## 做事的順序
1. 先把前端做好，放上 GitHub Pages 看得到
2. 最後才接上 Supabase

## 我不知道、需要你幫我決定並解釋的
- 前端要用什麼語言和框架
- Supabase 要怎麼設定
- 金鑰怎麼產生、要放在哪裡

## 新增功能（實作後補充）

基本需求以外，這個聊天室另外做了下面這些功能。怎麼試用、程式在哪裡，請看 `README.md` 的「新增功能」一節。

- 表情回應，可以看到是誰按的
- 編輯、收回自己的訊息
- 傳送圖片（Supabase Storage，一次最多 9 張）
- 圖片放大檢視
- 網址自動變成可以點的連結
- 分頁標題顯示未讀數
- 「有新訊息 ↓」按鈕
- 長訊息自動折疊
- 個人封鎖（只影響自己的畫面）
- 伺服器端的發送頻率限制與欄位檢查
- 24 小時自動清除（Edge Function + pg_cron）
- 主動離開馬上通知，斷線有 60 秒寬限
- 斷線重連
- 示範模式（網址加上 `?mock=1`）
